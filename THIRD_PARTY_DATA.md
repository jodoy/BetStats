# Third-Party Data & Licensing Policy

The repository license applies only to original BetStats source code and original documentation.

It does **not** grant rights to datasets, API responses, logos, images, trademarks or other content supplied by third parties.

## Mandatory SourcePolicy

Every provider integrated with BetStats must declare, at minimum:

- `CanDisplay`
- `CanCache`
- `CanStoreRaw`
- `CanStoreNormalized`
- `CanUseForTraining`
- `CanRedistribute`
- `CommercialUse`
- `RequiresAttribution`

Technical accessibility is not evidence of permission.

## Public repository rule

Do not commit:
- proprietary datasets;
- paid provider exports;
- API dumps whose redistribution rights are unclear;
- Footiqo premium files;
- secrets or credentials;
- copyrighted media without explicit permission.

Use synthetic, manually constructed, or explicitly redistributable fixtures for public tests and demos.

## Footiqo

Current project permission discussed with Footiqo is for private, non-commercial statistical analysis and prediction-model work. Commercial/public use must be separately verified before such data is used for that purpose.
