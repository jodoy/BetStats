# ADR 0028: Read-only football dashboard

Status: Accepted

## Context

BS-014 exposes governed historical football evidence and finalized model artifacts through a local bilingual dashboard. A displayed probability must never be generated by an HTTP read, and technical access does not confer display rights.

## Decision

Use server-interactive Blazor in Web, referencing Application only. Web calls a bounded API query port over HTTP; PostgreSQL remains Infrastructure-owned. Dashboard endpoints and the Web host are available only in Development on loopback connections with loopback host names. Remote access requires a separate authenticated deployment decision.

Project existing immutable datasets and finalized backtests into explicit presentation DTOs. Recheck current source purpose permissions and retention for every read. Reuse read-only inspection, verify stored canonical hashes and evidence bindings, and fail closed on denied, corrupt or missing evidence. Do not call backtest execution or reproducibility verification from GET handlers. Stored integrity verification is distinct from independently replayed accuracy.

Use bounded, stable server pagination and explicit competition, season, date, team and status filters. Preserve snapshot cutoffs and date-only precision. Expose no RAW content, storage paths, frozen internal records or policy evidence references. Metrics retain nullable/ineligible semantics; reports are never ranked across unequal samples.

An explicit Development-only presentation demo is separate from persistence. Every demo response and view carries DEMO; fictional examples do not claim observed model accuracy. No startup seeding, migration, import, prediction or evaluation is introduced.

## Consequences

No database migration or immutable contract change is required. Empty installations remain usable and explain missing evidence. The initial deployment is local only; an authenticated remote deployment is out of scope. Read verification checks stored artifacts and current rights, without claiming a fresh model replay.
