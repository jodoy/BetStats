# Football-Data.co.uk candidate assessment

Assessed **2026-10-08** against official pages, not third-party license claims.
No dataset was downloaded. This document paraphrases evidence; it does not copy
terms, provide a legal opinion, or approve a SourcePolicy.

Evidence: [data overview](https://football-data.co.uk/data.php),
[contact/use restrictions](https://football-data.co.uk/contact.php),
[format notes](https://football-data.co.uk/notes.txt).

Official access is country/season-linked CSV and spreadsheet downloads. The site
describes historical results, match statistics and odds; this slice only targets
match metadata. Div, Date, HomeTeam, AwayTeam and result indicators are documented.
Season comes from file context; no match UUID or universal team ID is documented.
No published numerical rate limit was identified on the reviewed pages.

The contact page warns against automated/commercial/training use and states that
silence is not permission. Public availability and the word free do not establish
BetStats rights. Do not send automated permission messages, approve a candidate
policy, or enable real retrieval. Unknown purposes deny under existing governance.
No candidate policy is seeded. The separately fictional synthetic source used in
the demo has no relationship to these rights. A future live integration needs
independent evidence, operator review, output/retention rights and a separately
implemented safe transport; this milestone has no HTTP client at all.
